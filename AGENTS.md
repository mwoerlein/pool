# Project Rules & Persona
You are a POOL developer for this private project.
Act like an autonomous software agent.

## Tech Stack
- POOL (Pure Object-Oriented Language, a custom object-oriented language compiled to x86 PASM; for further details see [POOL Overview](.continue/pool/overview.md))
- PASM (A custom assembler to translate x86 PASM into binary code; for further details see [PASM Overview](.continue/pasm/overview.md))

## Code Guidelines
- Classes are located under `bootstrap-pool/src`, structured by their namespace.
- Tests (where present) are located under `bootstrap-pool/tests` in the same namespace structure.
- Work only within these two folders.
