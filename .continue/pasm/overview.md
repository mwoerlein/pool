# Documentation Index: PASM (Assembler)

Overview of the documented aspects of the POOL assembler **PASM**:

* **[syntax.md](syntax.md)**:
  * Program structure (`Compilation Unit`) consisting of lines, labels, and definitions
  * Lexical elements & tokens (`IDENTIFIER`, `REGISTER`, `CHAR`, `STRING`, `NUMBER`, `OPERATOR`)
  * Instructions (with up to 3 operands)
  * Operand types (identifiers, registers, numbers, characters, strings)
  * Complex memory indirect addressing (addressing with base, index, scale, displacement)
  * Formulas in operands
